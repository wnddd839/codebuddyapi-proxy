把 CodeBuddy
变成 /v1.

把你的 CodeBuddy 账号，变成任何 OpenAI 客户端都能直连的 /v1 渠道。 Go 单文件二进制，OAuth 登录后协议直连，不需要 codebuddy --serve。

下载二进制 快速开始 · 源码
Capabilities

一件事做到位

不是多厂商聚合，也不是 Cursor 网关。这个项目只做一件事：CodeBuddy 账号 → OpenAI 兼容接口。

协议直连

默认 protocol_direct。OAuth 认证后直连上游，不必再挂 CLI serve，也不依赖任何外部浏览器插件。

标准 OpenAI 形状

GET /v1/models 与 POST /v1/chat/completions，流式与非流式完整支持。NewAPI、ZCode、Sub2API 按熟悉方式直连。

多账号轮询与熔断

账号池按区域隔离，遇到 429 速率限制时自动退避隔离 60s 并换号重试。凭据以 0600 权限原子落盘。

真实 Credits 余额

管理台直读官网用量接口，展示「剩余 / 总额」。一眼掌握账号余量，不是假状态。

国内 / 国际双区调度

端点以账号自身区域为准，不看反代机器出口 IP。国内号不误打海外，反之亦然。

Token 用量与思维链

流式收尾补发 usage chunk 与缓存统计；原生支持 reasoning_effort 与思考链内容流式透传。

Distribution

下载即用，无需安装

下载对应平台文件直接运行。首次启动会自动生成 API Key 并写入同目录 .env 文件。

平台 / Platform文件 / Executable
Windows x64 codebuddy-proxy-windows-x64.exe（兼容旧名 windows-amd64.exe）
Linux x64 codebuddy-proxy-linux-amd64
macOS Apple Silicon codebuddy-proxy-darwin-arm64
macOS Intel codebuddy-proxy-darwin-amd64

可选配置模板：.env.example · 校验和 SHA256SUMS.txt

Getting Started

三步跑起来

下载、运行、OAuth 登录三步即可。默认国内站，管理台可一键切换国际站。

01 /

运行二进制

下载对应平台单文件，双击或在终端启动。首次启动将自动创建 .env 并生成安全网关 Key。

02 /

进入控制台完成 OAuth

浏览器打开 http://127.0.0.1:32126/direct-admin/，点击「开始认证」完成登录，账号自动进入号池。

03 /

配置下游客户端

在 Cursor、Claude Code、OpenCode 或 NewAPI 中配置 Base URL 与网关 API Key，立即发起请求。

# Windows 示例 —— 直接运行
.\codebuddy-proxy-windows-x64.exe

# 或从源码构建
cd go-codebuddy && go run ./cmd/codebuddy-proxy

# 默认服务端点
API    http://127.0.0.1:32126/v1
Admin  http://127.0.0.1:32126/direct-admin/
