CodeBuddy Proxy

把你的 CodeBuddy 账号，变成任何 OpenAI 客户端都能直连的 /v1 渠道。 Go 单文件二进制，OAuth 登录后协议直连，不需要 codebuddy --serve。

下载运行 快速开始

Only CodeBuddy

一件事做到位

不是多厂商聚合，也不是 Cursor 网关。这个项目只做一件事：CodeBuddy 账号 → OpenAI 兼容接口。

协议直连

默认 protocol_direct。OAuth 后直连上游，不必再挂 CLI serve，也不依赖任何浏览器插件。

标准 OpenAI 形状

GET /v1/models · POST /v1/chat/completions，流式与非流式都支持。NewAPI、ZCode、Sub2API 按熟悉方式接入。

多账号轮询

账号池按区域分组，失败自动换号。凭据以 0600 权限原子落盘，刷新失败不会清空账号列表。

真实 Credits

管理台直读官网用量接口，展示「剩余 / 总额」。一眼知道账号还剩多少，不是假状态。

国内 / 国际一键切换

端点以账号自身区域为准，不看反代机器 IP。国内号不会误打到海外，反之亦然。

Token 用量透传

流式收尾补发 usage chunk，含缓存命中统计，缓存字段兼容多上游别名——客户端能拿到真实消耗。

Download

下载即用，无需安装

下载对应平台文件，直接运行即可。首次启动会自动生成 API Key 并写入同目录 .env—— 你不需要手动配置任何东西。

Get started

三步跑起来

下载、运行、OAuth 登录三步即可。默认国内站，管理台可一键切换国际站；也可从源码 go run。

范围说明：本项目只做 CodeBuddy 反代，不做 Cursor、也不做多厂商聚合。 
# Windows 示例 —— 直接运行，首次启动自动生成 API Key
.\codebuddy-proxy-windows-amd64.exe

# 或从源码
cd go-codebuddy && go run ./cmd/codebuddy-proxy

# endpoints
API    http://127.0.0.1:32126/v1
Admin  http://127.0.0.1:32126/direct-admin/
