从 sysc-Go 借什么，不借什么

sysc-Go 是终端 TUI 动画库（火焰、矩阵、光束、水族箱等）。Web 产品页应借「氛围语法」，而非 1:1 复刻 ASCII。

借 · 光束 Beams

斜向柔光 + 缓慢漂移，给 hero 深度。对应 sysc -effect beams 的「体积感」。

借 · 信号路由

两股珊瑚色粒子汇入薄荷色主流 —— 与 logo「多路进 / 单路出」同构，比纯装饰矩阵更贴产品。

借 · 稀疏 glyph 雨

极低透明度 falling chars，致敬 matrix 但不抢正文。密度远低于 TUI，避免「黑客屏保」廉价感。

调研摘要： sysc-Go（Nomadcxx，~143★）是 sysc-greet 登录器的 Go 动画库，纯 Go、可嵌入 TUI 或 CLI（syscgo -effect matrix -theme eldritch）。 Eldritch 主题为深底 + 青绿/紫调；我们保留现有 #0e1110 / #e88a4a / #5ec4a8，仅微量引入紫作 accent。 实现建议：Canvas 背景层 + CSS 玻璃内容层；prefers-reduced-motion 时关动画；移动端降粒子数。
